# Aidyn React App

This project uses [Vite](https://vitejs.dev/) for development and production builds.

## Available Scripts

In the project directory, you can run:

### `npm run dev` (or `npm start`)

Runs the app in development mode with hot module reloading.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Runs the test suite once with [Vitest](https://vitest.dev/).\
Use `npm run test:watch` for interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.

### `npm run preview`

Serves the production build locally for a quick sanity check.

### `npm run lint`

Lints the codebase with ESLint.
